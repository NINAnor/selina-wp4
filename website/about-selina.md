
# What is SELINA?
SELINA stands for **S**cience for **E**vidence-based and sustainab**L**e decis**I**ons about **NA**tural capital. It is an Horizon Europe project aimed at providing guidance for the protection, restoration and sustainable use of the environment. More information about SELINA can be found [here](https://project-selina.eu/).

All the content available in this website has been developed by the SELINA project (work package 4). To download the PDF of the report gathering all of website's content, plus addition more advanced material, click [here](https://project-selina.eu/library?type=1&Filter%5Bsort%5D=title+asc&search=guidelines).
